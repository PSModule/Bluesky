# Bluesky

Bluesky is intended to be a PowerShell module for interacting with the [Bluesky](https://bsky.app/) social network and AT Protocol APIs.

## Status

This repository is currently a placeholder. The module source contains only scaffold code, so none of the intended Bluesky and AT Protocol functionality is implemented yet. Real commands and usage examples will be documented once implementation begins.

## Documentation

When this module is implemented, command details should live in PowerShell help and generated documentation rather than being duplicated in this README.
